Seafloor Data Repository (SDR)

The purpose of the Seafloor Data Repository is to catalog and make available seafloor datasets in U.S. Atlantic waters collected by a variety of entities and purposes that can eventually be used to develop regional-scale seafloor habitat data products (e.g., bathymetry maps, benthic habitat maps, surficial seafloor geology maps) for wider use and dissemination via the Mid-Atlantic Ocean Data Portal and Northeast Ocean Data Portal, and other mapping platforms.

States, researchers, and private entities (including contractors and/or permittees) have submitted data to the Seafloor Data Repository. It can be accessed by clicking the Search Data tab above.

The associated documentation Submitting Data to the Seafloor Data Repository includes:

  • A list of federally-supported seafloor data repositories, including the Marine Geoscience Data System, whose holdings can be viewed on DataONE
  • Suggested contract language for funders to include in agreements to require data sharing via the Seafloor Data Repository
  • A list of accepted data types, formats, and resolutions
  • Instructions for submission
